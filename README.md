# Vitor Lopes · Portfólio

Portfólio pessoal construído com **React + Vite**, HTML, CSS e JavaScript.

Site: Hero com efeito de digitação, seção sobre mim, projetos em destaque
(com cards que reagem ao mouse) e contato — tudo com um visual "terminal",
divertido porém profissional.

## Rodando localmente

```bash
npm install
npm run dev
```

## Build de produção

```bash
npm run build
```

## Stack

- React 18 + Vite
- CSS puro (sem frameworks de UI)
- Efeitos: digitação animada, scroll reveal (Intersection Observer) e tilt 3D nos cards de projeto
